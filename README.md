# EuroTreino

Aplicativo de treino gamificado com ranking privado entre amigos. Cada treino registrado vira **Glória**, você sobe de rank do Recruta ao Olimpiano, e a disputa semanal acontece só dentro da sua **Legião** — nunca com desconhecidos.

> Em desenvolvimento.

## Stack

- **App:** React Native + Expo (TypeScript, Expo Router) — iOS, Android e Web
- **Backend:** Supabase — PostgreSQL, Auth, Row Level Security e Edge Functions

## Estrutura

```
app/        rotas do app (Expo Router)
src/        tema, componentes, funcionalidades e integrações
supabase/   migrações, testes do banco e Edge Functions
```

## Como rodar

As instruções de instalação entram junto com a inicialização do app.
